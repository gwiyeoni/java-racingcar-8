# java-racingcar-precourse

## 구현할 기능 목록

- [x] 입력
  - [x] 경주할 자동차의 이름을 입력받는다
  - [x] 시도할 횟수를 입력받는다
  - [x] 쉼표를 기준으로 자동차의 이름을 분리한다
- [x] Car 객체를 구현한다
  - [x] 0~9 랜덤값을 구한다
  - [x] 랜덤값이 4이상일 경우 해당 Car 객체가 전진한다
  - [x] Car 객체의 이름을 넘기기 위한 메서드 구현
  - [x] Car 객체의 위치를 넘기기 위한 메서드 구현
- [x] Game 객체를 구현한다
  - [x] 시도할 횟수만큼 라운드를 진행한다
    - [x] 차수별 실행 결과를 출력한다
  - [x] 게임 종료 후 우승자를 판별한다
  - [x] 단독/공동 우승에 따른 결과를 출력한다
- [x] 예외 처리
  - [x] 자동차 이름이 5자 초과일 경우 예외를 발생시킨다
  - [x] 자동차 이름이 잘못된 값일 경우 예외를 발생시킨다
  - [x] 시도할 횟수가 정수가 아닐 경우 예외를 발생시킨다
  - [x] 시도할 횟수가 1미만의 정수일 경우 예외를 발생시킨다
- [x] 테스트
  - [x] 자동차 이름이 잘못된 값일 경우의 예외 테스트
  - [x] 시도할 횟수가 잘못된 값일 경우의 예외 테스트
  - [x] 정상 값일 경우의 테스트
