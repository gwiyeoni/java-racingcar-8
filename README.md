# java-racingcar-precourse

## 구현할 기능 목록

- [x] 입력
  - [x] 경주할 자동차의 이름을 입력받는다
  - [x] 시도할 횟수를 입력받는다
  - [x] 쉼표를 기준으로 자동차의 이름을 분리한다
- [x] Car 객체를 구현한다
  - [x] 0~9 랜덤값을 구한다
  - [x] 랜덤값이 4이상일 경우 해당 Car 객체가 전진한다
- [x] Game 객체를 구현한다
  - [ ] 시도할 횟수만큼 라운드를 진행한다
    - [ ] 차수별 실행 결과를 출력한다
    - [ ] 시도할 횟수를 넘으면 게임을 종료한다
  - [ ] 게임 종료 후 우승자를 판별한다
  - [ ] 단독/공동 우승에 따른 결과를 출력한다
- [ ] 예외 처리
  - [ ] 자동차 이름이 5자 초과일 경우 예외를 발생시킨다
  - [ ] 자동차 이름이 잘못된 값일 경우 예외를 발생시킨다
  - [ ] 시도할 횟수가 정수가 아닐 경우 예외를 발생시킨다
  - [ ] 시도할 횟수가 1미만의 정수일 경우 예외를 발생시킨다
- [ ] 테스트
  - [ ] 자동차 이름이 잘못된 값일 경우의 예외 테스트
  - [ ] 시도할 횟수가 잘못된 값일 경우의 예외 테스트
  - [ ] 랜덤 값에 의한 자동차 전진을 확인하기 위한 테스트
